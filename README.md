# Ordo

Локальный ИИ-помощник для операционки компании (рабочее название).

- Прототип онлайн: https://timofeevaekaterinan-rgb.github.io/ordo-prototype/
- Исходник: [prototype/index.html](prototype/index.html). После правок – `python3 build_pages.py`, коммит и push, Pages обновится сам
- Ссылки на экраны: добавить к адресу `#home`, `#reports`, `#report`, `#acts`, `#review`, `#contracts`, `#contract`, `#law`, `#sources`

## Сценарий показа (5 минут)

1. **Сегодня.** Нажать микрофон, через 6 секунд запись распознается, прикрепится скриншот таблицы. Нажать стрелку, откроется отчет.
2. **Отчеты.** Открывается галерея из 6 отчетов: плитка или список, фильтр по отделам. Описать новый отчет в поле сверху – появится карточка «собирается». Открыть «Дебиторскую задолженность».
   Кликнуть сумму в таблице: видно, из каких документов 1С она сложилась. Написать комментарий в ячейке, версия обновится. Включить «Обновлять автоматически». Нажать на заголовок отчета – выпадающий список, переключиться на «Платежный календарь» (кассовый разрыв 20 ноября).
3. **Документы.** Календарь на ноябрь, 3-го отправка актов. Нажать «Проверить»: у «ТехноСтроя» +18% из-за доп. работ в CRM, у «Альфа Логистик» поменялись реквизиты. Подтвердить оба, затем «Все верно, отправить завтра».
4. **Договоры.** Галерея из 6 договоров с фильтром: черновики, входящие, на согласовании, действующие. Открыть «Договор подряда (их редакция)» от «СтройМонтажа» – 2 риска и пробел, нажать «Исправить все». Через заголовок переключиться на «Северлес»: неустойка, старый НДС 20%, срок претензии – «Исправить», текст в договоре поменяется. Счетчик замечаний в меню уменьшается.
5. **Право и налоги.** Ответ про НДС 22% простым языком: что поменялось, какие договоры затронуты, чек-лист по 1С.
6. **Источники данных.** Схема «все внутри сервера компании, 0 байт в сеть». Подключить почту.
7. Клик по профилю внизу слева – тарифы в рублях.
